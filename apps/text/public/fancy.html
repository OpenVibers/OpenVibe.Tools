Use it from code

One POST request runs the same engine as this page. There is no MCP server yet; the HTTP API is the way to script it.

curl -X POST https://openvibe.tools/api/v1/tools/fancy/run \
  -H 'Content-Type: application/json' \
  -d '{"input":{"text":"Hello World"}}'

# → {"state":"succeeded","tool":"fancy","result":{"data":{"styles":[...]}}}

Inputs and output are described at /api/v1/tools/fancy/schema. How the API works.
